## 🌟 Overview

This application is designed as a **comprehensive digital guide** for Pakistani MSCS applicants planning their fully funded scholarship journey. It combines curated educational guidance, interactive planning tools, and AI-assisted support in a single user-friendly experience.

### 🎯 What This Project Helps You Do

| Feature | Description |
|---------|-------------|
| 🌍 **Explore Scholarships** | Discover opportunities across 27 countries with detailed specifications |
| 📜 **Attestation Guidance** | Navigate Karachi / HEC / IBCC / MOFA verification processes |
| 📅 **Roadmap Planning** | Follow a structured timeline for the 2027-2028 application cycle |
| ✅ **Progress Tracking** | Monitor chapter completion and application milestones |
| 📄 **PDF Export** | Generate a professional, publication-quality guide |
| 🤖 **AI Assistant** | Get SOP reviews, cold email drafts, and attestation advice |

## ✨ Features

### 📚 Interactive Book Reader
- Chapter-by-chapter reading experience with progress tracking
- Collapsible sections for better readability
- Built-in checklist and action plan for each chapter
- FAQ sections with quick answers

### 🏛️ Attestation Guide
- Step-by-step verification flow for Matric, Intermediate, BS degree
- Karachi-specific office locations (BSEK, BIEK, HEC Gulshan, MOFA FTC)
- Fee estimates and processing times
- Common problems and verified solutions

### 🌍 Country Explorer
- 27 countries comparison matrix for MSCS programs
- Tuition costs, scholarship opportunities, and visa success rates
- Post-graduation salaries and PR pathways
- Interactive country cards with detailed modals

### 🎓 Scholarship Explorer
- 20+ fully funded scholarships database
- Eligibility requirements, benefits, and acceptance rates
- Country-specific filters and search functionality
- Official application links and document requirements

### 📊 Personal Trackers
- Document and attestation tracker with status updates
- Professor cold email tracker with reply status
- Local storage persistence for all data
- Customizable categories and deadlines

### 🤖 AI Assistant
- SOP review and improvement suggestions
- Professor cold email drafting
- HEC/IBCC/MOFA attestation guidance
- Powered by Google Gemini AI
- Context-aware responses for Pakistani applicants

### 📄 PDF Export
- Professional, publication-quality PDF generation
- Complete book export with all chapters
- Table of contents and formatting
- Offline reading and sharing capability
